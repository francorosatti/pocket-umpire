Voice Commands

Score Points

  • "punto uno" / "point one" - Point to Player 1
  • "punto dos" / "point two" - Point to Player 2
  • "juego" / "game" - Award game to player one point from winning

Set Exact Score

  • "quince cero" - Set score to 15-0
  • "treinta quince" - Set score to 30-15
  • "cuarenta treinta" - Set score to 40-30
  • "deuce" - Set score to deuce

Match Control

  • "deshacer" / "undo" - Undo last point
  • "reiniciar" / "reset" - Reset match
